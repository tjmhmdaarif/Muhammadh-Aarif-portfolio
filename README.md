## 👁️‍🗨️ What Is This?

**Burning Sakura: The Digital Ronin** is a production-ready, visually extraordinary, interactive developer portfolio that combines:

- **Japanese samurai-era art direction** with a burning sakura (resilience, discipline, transformation, forward movement)
- **Scroll-driven continuous visual storytelling** across 8 cinematic scenes
- **Real-time 3D** with Three.js + React Three Fiber + GSAP ScrollTrigger
- **My actual identity, projects, achievements, technical diagrams, and LinkedIn evidence**
- **High-end motion design** and carefully selected real-time 3D interactions
- **Interactive project case studies** with verified technical details
- **Exceptional responsiveness, performance, accessibility, and code quality**

It is **not** a static website mockup. It is a production-ready, immersive experience that feels like entering a cinematic Japanese world where ancient discipline meets modern intelligence.

## 🛠️ Motion System

**Core Techniques**:
- Scroll-scrubbed camera travel across 8 scenes
- Controlled parallax across 3 depth layers
- Mask-based text reveals
- Layered image reveals
- Subtle perspective and depth (no full-page wobble)
- Hover-responsive project imagery
- Restrained circular text paths for section markers
- Scroll-reactive environmental particles
- Directional ember movement
- A small number of playful micro-interactions

**Cursor**: Optional — only on suitable desktop devices, preserves normal cursor on touch

**Audio**: Optional and secondary — off by default, visible mute control, respectful of browser autoplay restrictions

**Motion Restraint**: Not every element animates. Motion explains and enhances content, never merely decorates.

## 🌐 TECHASHY Reference Adaptation

This project was informed by research on [TECHASHY 2.0](https://techashy.iiitkottayam.ac.in/), a premier technology hackathon powered by Betalabs at IIIT Kottayam. Adapted patterns:

- ✅ **Kanji section markers** (壱, 弐, 参, 肆, 伍, 陸, 漆) — consistent visual language
- ✅ **Color palette alignment** (obsidian, crimson, ember orange, gold)
- ✅ **Dark atmosphere + red accent** — core design system
- ✅ **Japanese-inspired editorial typography** — Shippori Mincho + Inter
- ✅ **Structured information hierarchy** — section numbers, eyebrow tags, metric grids
- ✅ **Skill constellation with ✦ markers** — same badge pattern as TECHASHY's track ✦ ✦ ✦
- ✅ **Achievement cards with verified evidence** — TECHASHY's "ALL PARTICIPANTS certificate" pattern noted
- ✅ **Scroll-triggered reveals with Framer Motion whileInView** — consistent animation pattern
